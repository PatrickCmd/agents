```
# Python program to calculate the first 10,000 terms of the series:
# 1 - 1/3 + 1/5 - 1/7 + ... and multiply the total by 4

# Define the number of terms
n_terms = 10000

# Initialize the sum
series_sum = 0.0

# Calculate the series sum
for i in range(n_terms):
    term = (-1)**i / (2*i + 1)
    series_sum += term

# Multiply the sum by 4 to get the final result
result = 4 * series_sum

# Print the result
print(result)

# Output:
# 3.1414926535900345
```
